# 🎯 Challenge Management

A dynamic **React.js application (built with Vite)** that helps users create and track personal challenges. Users can manage challenges by marking them as **active**, **completed**, or **failed**, with smooth animations powered by **Framer Motion**.

---

## 🚀 Features

### 🆕 Create Challenges

- Add new challenges with:
  - Title
  - Description
  - Date
  - Image
- Simple and intuitive form interface

### 📋 Challenge Tracking

- View all challenges in categorized tabs:
  - 🟢 Active
  - ✅ Completed
  - ❌ Failed

### 🔄 Status Management

- Mark challenges as:
  - Completed
  - Failed
- Dynamic updates across tabs

### 🎬 Animations

- Smooth UI transitions using **Framer Motion**
- Enhanced user experience with animations

---

## 🛠️ Tech Stack

- **Frontend:** React.js (Vite)
- **State Management:** React Hooks (useState, useEffect)
- **Styling:** CSS
- **Animations:** Framer Motion
- **Build Tool:** Vite

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

git clone https://github.com/mishraabhishek11/challenge-management.git

### 2️⃣ Navigate to the project folder

cd challenge-management

### 3️⃣ Install dependencies

npm install

### 4️⃣ Run the development server

npm run dev

### 5️⃣ Open in browser

http://localhost:5173
